# PrepTrack – Placement Preparation Performance Analyzer

## Team Lead Repository

---

# Project Overview

PrepTrack is a Python console application developed to evaluate a student's placement readiness based on academic eligibility, attendance, project completion, profile verification, and seven days of coding practice.

The application validates every input provided by the user, classifies each practice score, calculates the overall performance, identifies strengths and weaknesses, detects critical scores, and finally determines whether the student is ready for a placement mock interview.

This repository is maintained by the **Team Lead** to monitor the progress of all team members, maintain the repository directory, verify submissions, coordinate code reviews, and ensure that every member successfully completes the project according to the given requirements.
